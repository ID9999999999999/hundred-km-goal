# Open-Source Baseline

This project was planned after reviewing the public open-source running tracker **RootStep** as an architectural baseline.

RootStep demonstrates a relevant stack for this type of application:

- Flutter / Dart
- OpenStreetMap through `flutter_map`
- Geolocation through `geolocator`
- Local-first fitness tracking
- MIT license

This repository is a clean RDOS implementation for Yasser's personal 100 km objective. It does not import RootStep source code directly. The baseline is used to validate the technical direction and package family.
